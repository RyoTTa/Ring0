# Ring0 — 새 세션에서도 이어지는 프로젝트 기억

[[🇬🇧 English](README.md) · **🇰🇷 한국어**

코딩 에이전트는 세션이 끝나면 다 잊어버린다. Ring0는 그걸 고친다. 선호, 프로젝트 결정,
최근 작업을 프로젝트별로 저장하고 자동으로 떠올린다.

## 설치

에이전트에게 그대로 붙여넣어라:

```
https://github.com/RyoTTa/Ring0 의 ring-memory 스킬을 설치해줘. 저장소의 AGENTS.md를 참고해.
```

또는 🔗 [설치 안내](INSTALL.md)에서 OpenCode, Claude Code, Codex 방법을 확인해라.

## 동작 방식

한 번 말하면, 다음 세션부터 기억한다.

```text
You: 이 프로젝트는 pnpm을 써. 기억해줘.
Agent: 기억했어: 이 프로젝트는 pnpm 사용. (#1)

(다음 세션)
You: 패키지 매니저 뭐로 하기로 했지?
Agent: 저장된 결정은 pnpm이야. (#1)
```

## 뭐가 달라지나

| Before | After |
| --- | --- |
| 세션이 바뀔 때마다 스택, 규칙, 이미 정한 결정을 다시 설명한다. | 에이전트가 프로젝트 목표, 현재 결정, 다음 할 일을 이미 알고 시작한다. |
| "pnpm이였나 npm이었나?"에 추측으로 답한다. | 저장된 결정을 ID와 이력째로 답한다. |

## 네 개의 링

4단계로 기억한다. 자세한 규칙은 [SKILL.md](SKILL.md)에 있다.

1. **ring0 — 커널.** 핵심 정체성과 제약. 네 승인이 있어야 바뀌고, 2,000자 제한, 항상 전체가 로드된다.
2. **ring1 — 장기.** 선호, 사실, 결정. 기본 저장 위치이며 키워드 검색으로 찾는다.
3. **ring2 — 에피소드.** 세션 요약과 최근 결과. 고정하지 않으면 30일 단위로 감쇠한다.
4. **ring3 — 스크래치.** 임시 메모. 일이 끝나면 보관 처리한다.

삭제는 없다. 보관만 하며 이력은 남는다. 낡은 결정은 `supersede`로 대체 관계가
연결되고, 몰래 덮어쓰지 않는다.

## 호스트

| 호스트 | 방식 | 명령 |
| --- | --- | --- |
| OpenCode V2 | 자동 수집 + 회상 (프로젝트별) | `install.py --project 경로 --auto` |
| OpenCode | 필요할 때 쓰는 스킬 | `install.py --project 경로` 또는 `--global` |
| Claude Code | 필요할 때 쓰는 스킬 | `install.py --host claude --project 경로` 또는 `--global` |
| Codex | 필요할 때 쓰는 스킬 | `install.py --host codex --project 경로` 또는 `--global` |

Python 3.9+만 있으면 된다. pip 패키지, 별도 서버 없음. 저장소는 프로젝트 안
SQLite(`.agent/`)이며 프로젝트별로 격리된다.

## 조정하기

포크해서 `SKILL.md`와 링 정책을 고친 뒤 `--force`로 재설치해라.
에이전트 설치 체크리스트는 `AGENTS.md`, 호스트별 상세는 `INSTALL.md`에 있다.
